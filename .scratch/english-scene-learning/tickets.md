# 第一版实施工单索引

主工单保持不变；以下为用户批准的纵向切片。状态标签是分诊状态，不代表依赖已经完成。只有阻塞工单实际完成并验收后，后继工单才可开始。

| 工单 | 阻塞 | 可交付行为 |
|---|---|---|
| [02 导入素材并播放完整视频](issues/02-import-playback.md) | 无 | 用户在本机浏览器导入完整视频与英文字幕，在素材库查看并播放，支持跳转，重启后素材仍在。 |
| [03 完成一道无提示原句重构练习](issues/03-first-reconstruction.md) | 02 | 用户从固定练习包开始学习，在目标声音前暂停并居中填空，答对后自动听原句并继续剧情。 |
| [04 四档提示与直接揭晓](issues/04-hints-reveal.md) | 03 | 用户卡住时逐级获取帮助或直接揭晓，继续剧情，并正确保留尝试及提示使用记录。 |
| [05 跳转、重做与退出恢复](issues/05-seek-resume.md) | 04 | 用户可以自由跳转、回看、重做和退出，下次恢复原进度与作答内容，且不会循环弹题。 |
| [06 生成学习报告并保护未做题答案](issues/06-learning-report.md) | 04 | 用户在视频结束或主动结束时查看学习报告，集中理解表达与卡顿情况，同时不看到未做题的答案。 |
| [07 错题本自主复习](issues/07-mistake-review.md) | 04 | 用户从已保存卡顿题进入不看视频的中文填空复习，按 Enter 前进并自主管理掌握状态。 |
| [08 从字幕生成可学习的练习包](issues/08-generate-learning-package.md) | 04 | 用户导入素材后启动预处理，看到阶段进度，获得完整练习包并进入真实学习流程。 |
| [09 处理预处理失败并安全重试](issues/09-retry-preprocessing.md) | 08 | 用户遇到预处理失败时能理解原因、重试并复用有效产物，已有学习内容不被损坏。 |
| [10 自动跳过不可靠台词并验证播放边界](issues/10-safe-timing.md) | 05、08 | 用户可以直接学习适合的题目，不可靠台词自动跳过，无可用题时得到更换素材提示，不需要人工核准。 |
| [11 切换另一种模型适配入口](issues/11-alternate-model-adapter.md) | 09 | 用户可配置选择 Codex 或 DeepSeek，仍使用相同的生成、校验、失败及重试流程，学习端行为一致。 |
| [12 重新生成资料并保留旧版本学习记录](issues/12-package-version-history.md) | 06、07、09 | 用户为同一视频重新生成资料后从新版本独立开始，同时继续访问旧进度、旧报告和错题。 |

完成状态：01 主工单及 02–12 子工单均已 resolved。完整实现位于 `integration/english-scene-learning`，最终 37 项浏览器测试及生产构建通过。依赖表保留为实施记录；[最终验收](../../docs/evidence/acceptance.md)和[代码审查](../../docs/evidence/code-review.md)记录验证结果与适用限制。
