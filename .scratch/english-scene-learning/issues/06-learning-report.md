# 06: 生成学习报告并保护未做题答案

## Parent

[01：实现英语情境原句重构练习第一版](01-build-first-version.md)

## Specification

[完整规格](../spec.md)

**What to build:** 用户在视频结束或主动结束时查看学习报告，集中理解表达与卡顿情况，同时不看到未做题的答案。

**Blocked by:** 04（四档提示与直接揭晓）。

## Acceptance criteria

- [x] 视频结束和主动结束均记录本次学习范围与结束原因，并立即从已有资料和记录汇总报告，不调用模型。
- [x] 明确区分已完成、揭晓与未做题，统计无提示、提示等级和错误情况。
- [x] 已完成或揭晓题展示原句与句式卡；卡片包含用途、骨架或搭配、结构及迁移例句译文，可展开解释。
- [x] 未做或尚未答完的题只显示数量与位置，不展示原句和句式卡；使用过部分提示不解除此限制。
- [x] 报告可重新查看，刷新或服务重启不丢失已保存结果。
- [x] 浏览器验收正常结束、提前结束、未完成已用提示、报告重开及无模型调用。

## Comments

- 2026-10-25：按用户批准的纵向拆分发布。每张工单贯通必要的数据、接口、界面和应用级测试；主工单保持不变。

## Answer

2026-10-25：已实现主动结束/自然结束的持久化学习报告快照、分项统计、展开句式卡、未完成题的服务端与界面答案保护，以及素材库历史报告与报告 URL 恢复。结束回调与 05 协作，先等待作答保存再汇总；报告不调用模型。

红测试先因缺少结束入口失败；实现后生产构建通过，隔离环境完整 8 项浏览器测试通过（55.9 秒）。包括三种结果混合、部分提示未完成、自然视频结束自动报告、历史重开、刷新及真实 API 进程停止/重启后读取同一报告。完整证据、范围与截图见 `docs/evidence/ticket06.md`。
