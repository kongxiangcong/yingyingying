## Acceptance criteria

- [x] 覆盖外部模型超时、异常返回、非法结构、原文改写、重复题、越界索引和词数不一致，显示失败阶段与原因。

- [x] 失败不替换已有可用版本；发布中断不暴露半成品，不重复制造冲突结果。
