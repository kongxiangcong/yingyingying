- [x] 凭据仍只在环境或本地配置中，日志和练习包不包含秘密。
- [x] 应用级测试分别替换两种外部响应，比较最终可学习行为；明确真实入口验证与固定响应测试的证据区别。

## Answer

2026-10-25：已接入独立 DeepSeek Harness 适配器，与 Codex 使用不同 argv、配置覆盖、权限环境及事件解析；入口/模型可由配置选择。DeepSeek 通过临时 agent-default-model patch 明确选择实际供应商与模型，要求 final 和成功 turn_end，同样经过原句/提示/卡片校验、有限重试、缓存与发布。包保留实际供应商 ID、模型、提示版本和来源，完整保留 10 的声音认证元数据。

首次红测试为 DeepSeek 入口不支持；实现并合并 10 后，两个入口分别贯通固定响应生成和浏览器连续学习。AUTH、未知秘密错误码及缺失结束事件均安全失败，旧包不被替换，公开任务/页面/服务日志不泄露模拟秘密，界面重试成功。真实模型未调用，未操作凭据；只检查本机 CLI help 和现有入口源码，不将固定响应视为真实服务验证。

隔离环境完整 28 项浏览器测试通过（5.4 分钟），生产构建通过。证据见 docs/evidence/ticket11.md。
