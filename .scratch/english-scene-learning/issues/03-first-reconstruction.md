**What to build:** 用户从固定练习包开始学习，在目标声音前暂停并居中填空，答对后自动听原句并继续剧情。

## Acceptance criteria

- [x] 固定版本化练习包关联素材、来源字幕、时间表、单词单位及预生成资料；作答记录关联包版本与题目，不依赖模型。
- [x] 浅灰半透明蒙版覆盖暂停画面，中文大字与逐词横线居中，长句换行、焦点突出，文字保持清晰。
- [x] 目标原句揭晓前不通过字幕或预览泄露；真实短视频验证暂停前不播放目标声音，不能只用暂停标志证明。
- [x] 完整单词匹配立即标绿；未完成输入中性；空格、Tab、Enter 或失焦才检查错误，单次操作不重复计数。
- [x] 忽略大小写、首尾空格与弯直撇号差异；缩写和连字符词各一空、句末标点直接显示，不接受同义改写。
- [x] 整句答对自动收起蒙版、播放原句并显示英文，随后继续剧情；保存无提示通过、输入及错误次数。
- [x] 应用级测试演示连续至少两题、输入边界、结果保存和学习过程中无模型请求。
