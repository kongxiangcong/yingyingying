## Acceptance criteria

- [x] 前跳不补弹沿途题目，不将跳过题标为完成；回看不重复弹已完成题，未完成题仍在正常到达暂停点时触发。
- [x] 提供主动重做及原句重播，保持历史，不与自动触发产生循环。
- [x] 作答中退出后恢复输入与最高提示等级，观看中退出后恢复播放位置。
- [x] 恢复剧情先暂停，由用户主动播放；重载与服务重启后状态不丢失。
- [x] 通过真实浏览器及媒体验证跳转、重播、恢复和临近暂停点的行为，扩展声音不泄露检查。
