# 08: 从字幕生成可学习的练习包

## Parent

[01：实现英语情境原句重构练习第一版](01-build-first-version.md)

## Specification

[完整规格](../spec.md)

**What to build:** 用户导入素材后启动预处理，看到阶段进度，获得完整练习包并进入真实学习流程。

**Blocked by:** 04（四档提示与直接揭晓）。

## Acceptance criteria

- [x] 独立 Python 工作进程运行检查、解析、上下文、选句、资料生成、确定性组装、校验与发布流程，交互服务仍可响应。
- [x] 先检查已有可复用 harness，再实现一种确认可用的模型适配入口；供应商、模型和超时等可配置，凭据不进入日志或包。
- [x] 处理跨字幕台词、多说话人及长素材分块重叠，保留来源标识并避免重复题。
- [x] 保留字幕英文原文；结合上下文生成中文、揭词建议与句式卡，程序生成或校验词单元、索引和重复候选。
- [x] 按时间表关联字幕时间，模型不得猜声音边界；仅在完整校验后发布，半成品不可学习。
- [x] 界面显示阶段、成功或明确失败；已生成资料可进入与固定包相同的学习流程。
- [x] 自动化以固定模型响应贯通生成到浏览器做题；真实服务验证须满足运行时凭据条件，不把固定响应通过视为真实模型验证。

## Answer

2026-10-25：已实现独立 Python 预处理进程、持久化八阶段任务状态、跨字幕台词与保守多说话人处理、上下文分块重叠去重、Codex argv 适配、确定性原文/词单元/提示/句式卡校验与原子版本发布。素材库可启动并查看阶段，生成内容贯通真实浏览器学习。

初始红测试缺少生成入口；实现后完整 7 项浏览器套件通过（42.9 秒），生产构建通过。外部模型在测试中使用固定 Codex JSON 事件脚本，真实模型未调用；已通过本机 CLI help 检查实际参数。字幕间隙仅作为候选，不宣称真实声音边界已验证，09/10 分别补齐故障恢复及自动声音可靠性。证据见 docs/evidence/ticket08.md。
