# 实现英语情境原句重构练习第一版

## Specification

按[完整规格](../spec.md)实施，领域术语与规格保持一致。该工单覆盖第一版完整闭环，不把尚未实现的能力视为已验证。

## Scope

- 本地素材导入、状态和可重试预处理，校验后发布版本化练习包。
- 完整视频按时间表暂停，居中灰色蒙版填空、四档提示、实时匹配、答对后自动继续。
- 进度与作答历史持久化，学习报告保护未做题答案。
- 错题本自主中文填空复习、统一 Enter 下一题、手动掌握标记和历史保留。
- 练习包重新生成不覆盖旧进度与错题。

## Acceptance

- 完成规格中的全部用户行为及 Testing Decisions 场景。
- 浏览器操作完整应用是主要验收入口；测试时外部模型使用固定响应，真实视频验证暂停及声音不泄露。
- 功能测试、媒体验证和未覆盖的环境限制如实记录；不能以伪时钟或暂停状态替代实际音频证据。
- 不引入自动复习调度、复习视频播放、自动复习下一题或用户逐题人工核准。

## Suggested Delivery Order

1. 核验运行环境和媒体工具，以固定练习包实现视频学习、记录及报告。
2. 接入独立预处理流程和模型适配边界，验证完整发布与失败重试。
3. 使用真实素材验证时间边界、字幕、跳转和恢复。
4. 完成错题本及版本隔离，执行应用级验收。
