## Acceptance criteria

- [x] 默认全空；Tips 揭示部分词；Pro 提供剩余打乱候选且保留重复数量；Pro Max 显示并填入完整答案。
- [x] 提示递增、下一题重置，独立直接揭晓可越级，进入原句播放并继续剧情。
- [x] 各提示档位空位一致，揭词索引合法；与原始输入冲突时显示原词并保留原始尝试。
- [x] 完成状态与最高提示等级分开保存，未答完但用过提示仍为未完成；自行改错不使用提示仍为无提示通过。
- [x] 直接揭晓按 Pro Max 记录，不能因程序自动填入答案被误判为无提示通过。
- [x] 浏览器验收各档提示、重复词、冲突输入、未完成状态及下一题重置。
