**What to build:** 用户可以直接学习适合的题目，不可靠台词自动跳过，无可用题时得到更换素材提示，不需要人工核准。

**Blocked by:** 05（跳转、重做与退出恢复）、08（从字幕生成可学习的练习包）。

## Acceptance criteria

- [x] 实现并说明可验证的边界可靠性判断，结合真实素材验证字幕偏移、跨字幕句子、紧接对白和多说话人，不假定合法时间即真实发声时间。
- [x] 无法确认安全暂停的候选自动跳过；没有可用题时页面明确提示更换素材，而非发布空包或要求用户修时间。
- [x] 暂停不得泄露目标声音或任意截断前句；对播放器延迟导致的问题修正播放策略，不能全部归为素材问题。
- [x] 如需音频对齐，先验证必要性及实现成本，不引入视频视觉理解或模型猜时间。
- [x] 以已下载并核验的小猪佩奇样本及边界夹具演示生成至学习，实测正常播放、跳转、重播、恢复的声音边界。
- [x] 保存媒体测试证据与适用限制；仅 DOM 暂停或伪时钟测试不足以通过验收，测试人员验证不等于用户逐题核准。
