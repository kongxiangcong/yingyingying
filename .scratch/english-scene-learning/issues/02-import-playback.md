# 02: 导入素材并播放完整视频

## Parent

[01：实现英语情境原句重构练习第一版](01-build-first-version.md)

## Specification

[完整规格](../spec.md)

**What to build:** 用户在本机浏览器导入完整视频与英文字幕，在素材库查看并播放，支持跳转，重启后素材仍在。

**Blocked by:** None (can start immediately)。

## Acceptance criteria

- [x] 提供可启动的本机应用，贯通界面、本地服务及持久化；采用规格已定技术栈并记录运行方式。
- [x] 检查实际视频与音频编码、文件可读性和字幕时间格式；支持约定的 MP4、SRT、VTT，错误有明确说明。
- [x] 完整视频可按区间读取与跳转，默认显示英文字幕、不显示中文字幕；不物理切割视频。
- [x] 素材库能显示登记素材及状态，重载或服务重启后仍可读取。
- [x] 使用项目本地小猪佩奇测试素材（素材准备记录明确可用后）或确定性短视频夹具，通过浏览器验收导入、错误、播放及跳转。

## Comments

- 2026-10-25：按用户批准的纵向拆分发布。每张工单贯通必要的数据、接口、界面和应用级测试；主工单保持不变。


## Answer

2026-10-25：已实现 FastAPI / SQLite 与 React / TypeScript / Vite 应用。用户通过浏览器上传完整本地视频和字幕，FFmpeg 检查实际 MP4 / H.264 / AAC 与时长，解析 UTF-8 SRT/VTT，检查时间格式、顺序及范围。媒体复制至本地数据目录，支持 HTTP byte ranges。素材库持久化，播放器默认英文字幕，原文件无需切割。

验证：先运行缺少界面的真实浏览器测试，在视频文件输入定位处失败；实现后 `npm.cmd run build` 通过，`npx.cmd playwright test` 三项通过（11.3 秒）：Peppa 实际素材导入、重载保留、真实播放及跳转；非法字幕、NaN/逆序/越界时间；VTT、206 范围读取、伪 MP4 实际编码拒绝。测试运行真实 FastAPI、SQLite、React 与 HTML video；跨多轮服务重新启动仍读取原素材库。启动和依赖说明见根 README。

边界：此工单只验收完整视频播放与素材导入，没有宣称目标声音暂停精度或字幕与声音精确对齐。FFmpeg 不可用时显示明确错误；不实施自动转码。测试素材需按已有 README 准备，未将有版权的 MP4 纳入 Git。
