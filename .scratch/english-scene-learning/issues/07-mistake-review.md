# 07: 错题本自主复习

## Parent

[01：实现英语情境原句重构练习第一版](01-build-first-version.md)

## Specification

[完整规格](../spec.md)

**What to build:** 用户从已保存卡顿题进入不看视频的中文填空复习，按 Enter 前进并自主管理掌握状态。

**Blocked by:** 04（四档提示与直接揭晓）。

## Acceptance criteria

- [x] Tips、Pro、Pro Max 及直接揭晓的卡顿题按原题与版本收录，保留提示程度和历史，不以单纯输入错误改变无提示分类。
- [x] 错题本独立入口，由用户决定何时开始；直接中文与英文空位、从无提示开始，不加载或播放视频。
- [x] 沿用实时匹配及提示机制；未完成题与未揭晓题不能通过错题列表提前看到完整答案。
- [x] 所有答对或揭晓结果统一停留，新的 Enter 才进入下一题；未完成的 Enter 仅检查单词，重复按键不能连跳。
- [x] 答对不删除、不自动标记掌握；手动标记已掌握后默认不练，但可查看并重新加入。
- [x] 保存复习历史与用户掌握标记，不建立到期队列、复习间隔或提醒。
- [x] 浏览器验收题目收录、各种提示下 Enter 行为、手动掌握、重新加入及持久化。
