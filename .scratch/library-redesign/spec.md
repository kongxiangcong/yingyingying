主任务：从节目单找到视频，查看详情并开始学习。左侧仅素材库、学习报告、设置；右上角上传素材，原生模态窗选择视频、可选英文字幕和节目。视频卡片打开详情，详情使用既有生成流程。节目支持创建、归类且服务端持久化；已有佩奇标题自动归入小猪佩奇，可手动调整。报告下有报告/错题本，能力分析明确为后续开发。

学习：左上角可折叠控制区集中返回、模式、设置、总结；模式选择后收起。非全屏顶栏显示标题和状态；浏览器全屏隐藏顶栏及常驻控件，仅保留视频、字幕和题目，鼠标移至左上角或键盘聚焦可唤出菜单。蒙版、版本、播放控制、题目回顾进入设置。移除面向用户的 JSON 练习包导入，不移除服务 API。

上传能力：MP4 H.264/AAC 和独立 UTF-8 英文 SRT/VTT；仅视频时提取内嵌英文文本字幕。烧录字幕不等于文本字幕，当前无 OCR，失败时明确要求补充字幕，保留文件供重试。不调用付费模型或改动已有预处理配置。

保留：素材/练习版本 ID、进度、报告、错题、提示计分、声音边界、持久化及恢复。现有未提交工作不回滚。API 新增节目组织、可选字幕和封面，已有上传调用兼容。
