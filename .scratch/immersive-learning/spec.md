# 沉浸式学习 UI
mode: Integrate
visual_policy: redesign

以用户 2026-10-25 截图与要求为视觉依据，替代旧规格中「库底部播放器 + 半透明填空层」的布局。数据、API、版本隔离、提示计分、保存及自动续播不变。

学习入口仍为素材库播放。进入后隐藏素材库，独立一屏学习；中文和下划线居中。正式采用已确认的 A 全屏沉浸方案：剧情画面铺满学习窗口，中文与空位位于中央。提供填空、看剧情、句式卡，切换不重建播放器或作答。蒙版默认 74%，可在 50–90% 间调整并保存在本机；纯剧情状态不施加蒙版。作答中看剧情只查看暂停帧，句式卡仅开放已经完成的原句。错题复习共用输入控件与居中布局。设置、导入、回顾按需展开；长设置/记录允许局部滚动。素材库、报告是资料浏览，保留必要滚动。

数值来源：src/style.css 的 immersive learning 区域。无新增动画、依赖、付费请求。参考仅为用户图片，无参考代码复制。

状态板：播放（视频占据主体）、作答（居中文本与空位）、提示（候选词与原始作答）、设置/回顾（按需展开）、复习（无视频居中）、加载/错误（保留服务反馈）。

验收：build；Playwright 实际本机服务，1440×900、1024×768、390×844、320×740、844×390；验证无页面溢出、切换保留草稿、提示/续播、返回素材库、键盘。极端放大/高度允许练习局部滚动以免裁切。未运行原生 IME/读屏不能声明通过。
