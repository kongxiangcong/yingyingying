# 05 跳转、重做与恢复验收

日期：2026-10-25。测试代码：`tests/seek-resume.spec.ts`、`tests/service-restart.spec.ts`；使用项目隔离 Python、真实 FastAPI、SQLite、React 与 H.264 / AAC 媒体。

## 行为与保存

红测试先到达第二题、使用 Tips 和错误输入后，公开 progress 接口的 active_question_id 仍为空而失败。实现后：

- 向前跳到 4.42 秒，第一题保持未做；正常到达 4.5 秒暂停点触发第二题。跳转只重置自然经过基线，不补弹沿途题目。
- 第二题使用 Tips，输入 Wrong 并退出重载；自动恢复原蒙版、原始输入与最高提示，视频保持暂停。
- 提示答对后回看，不重新弹已完成题；“重播”可实际播放原句。
- 主动重做从空白、无提示开始：第一次以直接揭晓完成，第二次无提示完成。公开历史保留 generation0 的提示通过、generation1 的揭晓及 generation2 的无提示通过，不把过去最高提示混入新尝试。
- 第一题仍未完成，回到片头后自然到达暂停点会再次触发，答对后正常播放目标声音。

版本专属 progress 保存整数毫秒位置与当前题。正常页面退出/切到后台时发送 keepalive；单调 revision 防止早期在途请求覆盖最新位置或输入。generation 还阻止旧重做代次的迟到请求污染新记录。输入的原始形式保持不变。

## 真实声音观测

沿用 03 的被动输出图 PCM 观测，不替换媒体或播放器时钟。目标一 660 Hz，目标二 1760 Hz，前文 220 Hz。一次通过运行：

| 场景 | 220 Hz | 660 Hz | 1760 Hz |
|---|---:|---:|---:|
| 近暂停点前跳后到第二题 | 0 | 0 | 0 |
| 重载恢复作答蒙版 | 0 | 0 | 0 |
| 主动重播第二题 | 0.002154 | 0.002515 | 0.403489 |
| 回看片头到未做第一题 | 0.399910 | 0.000112 | 0.000004 |
| 第一题答对后 | 0.399910 | 0.399741 | 0.000020 |

未播放目标阈值 <0.01，已播放目标 >0.05。回看前文可听，同时未做目标保持在低底噪；重播与答对后的目标真实输出，不只检查 DOM paused。

## 真正服务重启

测试独立启动 FastAPI 与 Vite，使用固定临时 SQLite / 包目录。保存观看书签 3.3 秒后停止并重新启动实际 Python 进程，刷新浏览器，位置恢复 3.3 秒且暂停。主动开始后到第二题、使用 Tips 并输入 Wrong，再停止并重新启动 Python 进程；刷新后恢复第二题蒙版、Wrong 与 Tips1，视频停在 4.511 秒，目标音频图输出为零。两次重启复用同一真实目录，不通过替换内部状态模拟重启。

## 结果与限制

生产构建通过；当时完整套件 7 项通过（49.7 秒）。随后增加退出在途写保护及近边界 80ms 跳转后，两项受影响测试再次通过（27.5 秒）。测试输出附 seek-resume-pcm.json 与 service-restart.json。

声学证据限于浏览器真实音频图出口，没有录制物理扬声器/声卡；确定音调夹具能验证播放路径，不能替代对小猪佩奇未知字幕偏移的自动安全判断，后者由 10 继续验证。正常页面退出有刷写保护，强杀浏览器/系统断电前尚未提交的写入不作耐久承诺。

最终合并 06 学习报告与 08 预处理集成后，生产构建通过，完整 12 项浏览器测试通过（1.4 分钟），包括报告的主动结束/自然结束/真实服务重启，独立预处理到真实学习，以及本工单的 PCM 和重启证据。
