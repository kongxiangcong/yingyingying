## Spec

- **[P2] 素材库没有学习位置。** 规格第 24 行要求“看到素材列表、处理状态和学习位置”。`server/app.py:54` 只返回名称、时长和状态，`src/main.tsx:52` 也只显示这些内容。用户必须先打开素材才能知道恢复位置，无法按进度选择学习单元。

- **[P2] 发布包缺少文件指纹和完整生成配置。** 规格第 130 行要求“练习包包含素材身份与文件指纹、生成配置与来源”。`server/preprocess_worker.py:231`、`server/model_adapter.py:130` 和 `server/learning.py:44` 只保留素材 ID、来源字幕、供应商／模型／提示版本及声音证书。视频哈希和生成配置只存在任务内部指纹中，未随版本包保存，无法独立核对包与原始素材、生成设置的对应关系。
- **[P2] 左弯撇号会拆开缩写。** 规格第 113–114 行要求“缩写……各占一空”“忽略……弯直撇号差异”。`server/learning.py:8` 的词正则支持 `'` 和 `’`，遗漏 `‘`。实际检查 `tokenize("Don‘t stop.")` 得到 `Don`、`t`、`stop` 三空，而 `normalize("Don‘t")` 又返回 `don't`。应统一分词与匹配的撇号集合。
