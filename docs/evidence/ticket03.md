# 03 原句重构与真实媒体证据

日期：2026-10-25。工单：`.scratch/english-scene-learning/issues/03-first-reconstruction.md`。

## 验证方法

`tests/reconstruction.spec.ts` 用本地 FFmpeg 生成 8 秒真实 H.264 / AAC MP4：前文为 220 Hz（0.2–0.5 秒）；目标一 660 Hz（2.2–2.7 秒）；目标二 1760 Hz（5.2–5.7 秒）。字幕含缩写、连字符、逗号和句末标点。暂停点为 1.5 秒及 4.5 秒，位于确定静音区。通过浏览器上传素材与固定包后真实播放并连续回答两题，没有模拟媒体时钟。

观测器只在浏览器初始化时，给真实 Web Audio 输出图增加被动 PCM 采样支路；保持原有输出通路，不替换播放器、增益、媒体流或应用代码。2048 帧 Hann 窗频率测量，记录每个已知频率的峰值振幅。校验前文确实可听、目标一在首次暂停前未出现、答对后目标一确实播放、第二次暂停前目标二未出现、答对后目标二确实播放。

一次通过运行的结果：

| 阶段 | 220 Hz | 660 Hz | 1760 Hz |
|---|---:|---:|---:|
| 第一次暂停 | 0.399849 | 0.002337 | 0.000298 |
| 第二次暂停 | 0.399849 | 0.401859 | 0.001174 |
| 第二题答对后 | 0.399849 | 0.401859 | 0.399733 |

已播放目标阈值 >0.05，未播放目标阈值 <0.01；非零底噪与短窗频率串扰不视为目标声音。测试输出附 `rendered-pcm.json`，可复核每轮实测值。

## 用户行为与持久化

先运行完整浏览器红测试，因缺少“固定练习包”入口失败。实现后生产 TypeScript/Vite 构建通过，完整套件 4 项通过（20.5 秒）。随后更换频率以进一步降低窗串扰，单项真实媒体测试通过（17.4 秒）。

流程覆盖：两个连续目标、中文居中灰蒙版、英文字幕隐藏、三个词空位、缩写/连字符各一空、未完成输入中性、Tab 与失焦不重复计错、弯撇号/大小写/外部空格归一化、自动播放原句、版本关联输入/错误/完成记录、刷新后读取持久化结果。浏览器公开 attempts 接口确认第一题 `errors=1`、`highest_hint=0`、`completed=true` 及原始输入保留；整个学习过程请求都在本机应用同源内，没有外部模型请求。

## 适用限制

该证据测量真实媒体在浏览器音频图出口的 PCM，没有录制操作系统扬声器或物理声卡回环。它证明本机 Chromium、确定静音边界和当前输出图下的目标音未在作答前到达输出，不承诺所有设备、后台节流或未知字幕偏移的统一保证。小猪佩奇已用于 02 实际导入播放，但其候选时间尚未据此变成可靠产品时间表。字幕偏移、紧接对白、跳转、重播、恢复与真实台词自动安全判断由 05/10 继续验收。

运行：PowerShell 设置 `SCENE_API_PORT=8003`、`SCENE_UI_PORT=5176` 后 `npx.cmd playwright test`；必要时显式使用 `$env:` 语法设置环境变量。FFmpeg 路径沿用根 README。

## 集成回归修正

集成复验发现：播放器在异步读取包目录时已出现在 DOM，但保护逻辑会阻止启动，旧导入测试直接 `play()` 因而被 `pause()` 中断。已先复现红测试，再将真实播放器的可用时刻绑定资料加载完成：期间显示“正在读取学习资料”，成功后显示可访问标签“播放器已就绪”与原生控件；加载失败时保持不可播放并显示原因。仍保留答案保护，不用等待固定秒数绕过竞态。导入测试通过公开就绪标签及控件启动。

修正后生产构建通过，完整四项浏览器测试通过（20.3 秒），包括真实 PCM 检查。Playwright 可用 `SCENE_PYTHON` 指定隔离 Python 可执行文件。
