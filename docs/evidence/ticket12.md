日期：2026-10-25。此记录覆盖重新生成后的版本隔离；最终集成代码审查与主工单关闭由集成流程另行记录。

## 红绿与版本流程

浏览器红测试先因缺少“练习包版本”选择框失败。实现后版本流程通过（34.3 秒）；合并 10 的声音策略并补充旧错题句式卡绑定验证后再次通过（32.9 秒）。生产构建通过。

有旧包时显示“重新生成练习包”，明确说明旧记录保留。播放器上方可选具体版本，显示版次和包标识；每个版本使用独立播放器生命周期，恢复自己的进度并保持暂停。选择偏好保存在本机浏览器，学习记录由本地服务持久化。新包发布不会静默切走正在看的旧版本。

`tests/versions.spec.ts` 启动真实 FastAPI、Vite、SQLite、独立工作进程及真实 H.264/AAC 媒体，验证：

1. 生成旧版，揭晓第一题，主动结束保存旧报告与句式卡。
2. 从界面重新生成，新旧包题号完全相同、包 ID 不同；固定外部模型响应使用不同题意和卡片标记。
3. 选新版时 attempts 为空、progress 为 0，无旧完成题或提示。新题使用 Tips 并保存独有输入 `new-attempt`。
4. 切旧版仍有已完成题与旧位置，切回新版恢复独有输入与提示。
5. 外部模型边界注入非法结构，重新生成明确失败；只保留已有两个可读版本，旧包完整 JSON 与原先相同。
6. 停止实际 API 进程并以同一数据目录重启，刷新后新版输入恢复，旧版已完成题仍可访问。
7. 旧报告整份快照及旧用途不变；错题本存在同题号、不同包版本的两条记录。
8. 实际进入旧错题复习，页面无 video，复习题接口的句式卡仍是旧版。

模型只在外部进程边界使用 `tests/fixtures/version_model.py` 固定响应；它确认只读入口且未接收视频。旧/新版中文标记用于版本关联验证，不是生成质量证据。声音边界沿用 10 的显式固定对齐入口与真实媒体检查。
