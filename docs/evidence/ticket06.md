# 06 学习报告验收

日期：2026-10-25。使用真实 Chromium、React 前端、FastAPI、SQLite、版本化练习包与真实 H.264/AAC 短视频。Python 使用根目录独立 `.venv`。没有模型请求或模型凭据。

## 红绿结果

首先新增完整应用测试：第一题无提示答对、第二题直接揭晓、第三题只用 Tips 后主动结束。红测试因缺少“结束本次学习”入口失败。与 05 协作提供可选播放器结束回调，结束前等待已有作答保存队列；其余报告代码独立于播放器。

实现后主动结束场景通过；随后增加自然视频结束与实际 API 进程重启场景。最终生产构建通过，隔离环境完整 8 项浏览器测试通过（55.9 秒），包括此前导入、提示和实际 PCM 回归。

## 已验证行为

- 主动结束立即生成报告，分别显示已完成 1、揭晓 1、未做题 1、无提示通过 1、卡顿题 2；只用部分提示的第三题保持未完成。
- 报告保存学习包版本、素材、开始/结束位置、结束原因和创建时间。开始位置和结束位置按导航事实分别记录，允许回看后结束位置小于开始位置。
- 已完成和揭晓题展示原句、中文、用途、表达骨架与可展开的结构解释、迁移例句和译文。
- 未做题只保存题目标识与位置。浏览器界面及公开报告 JSON 均不含未做题英文、中文、原始输入或句式卡。部分提示不会解除完整答案保护。
- 报告是持久化快照；浏览器刷新和素材库“查看学习报告”入口都可重新打开，无需读取模型。
- 三题依次揭晓后真实视频自然播放到结尾，自动打开报告；只发起一次报告创建请求，原因记录为视频结束。
- 独立测试启动真实 API 与 Vite、通过浏览器导入并生成报告，停止该 API 进程，再以同一数据目录重启。保持同一报告 URL 刷新后报告仍可读取，3 道未做题的答案继续隐藏。测试仅停止自己创建的服务进程。
- 主动结束全流程的浏览器请求均为本地同源，没有外部模型请求。
