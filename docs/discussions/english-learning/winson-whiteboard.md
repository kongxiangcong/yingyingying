# 英语情境表达练习：讨论白板

更新：2026-10-25

## 目标与边界
- 用户已有英语知识，重点练习在具体情境中组织自然表达。
- 第一阶段按演员原句练习 pattern；之后再考虑接纳多种表达。
- 不引入 AI 评分，优先保持练习流畅。
- 每句练习结束后总结句子结构、句式等可复用内容。

## 已确认流程
1. 播放剧情，提供上下文。
2. 在选中的目标台词开口前暂停，不预播目标句。
3. 展示中文和逐词空位。
4. 每题从全部留空开始，依次支持部分揭词、部分揭词加打乱候选词、完整答案并自动填入；下一题重置。
5. 作答后播放原句，对照表达，继续剧情。
- 素材导入后提前分析和规划，避免播放时临时出题。
- 挑有学习价值的表达，默认跳过简单语气词和普通寒暄，保留剧情连续性。

## 句后总结（用户已确认方向）
- 将句式总结接在原句播放之后，采用简短表达卡：情境意图、原句、可替换句式、一个迁移例句。
- 总结与题目一起预生成，练习时直接读取；详细解释按需展开。
- 原句匹配用于对照，不据此判断用户其他表达是否成立。

## 减法记录
- 用户明确推迟 AI 评分和多表达接纳，待核心练习流程稳定后再考虑。
- 建议先不做逐词语法解析和长篇讲解，避免打断表达练习。
- 已确认以本地视频和配套英文字幕作为第一版输入；建议先用小样验证暂停点、选句和提示流程。
